# Анализ рынка стартапов и венчурных инвестиций

## О проекте

Исследование исторических данных о стартапах и их финансировании по 2014 год включительно. Цель — оценить состояние венчурного рынка и определить перспективные направления инвестирования **с позиции начала 2015 года**.

Проект выполнен в формате аналитического кейса: от подготовки данных до анализа структуры рынка, динамики инвестиций и формирования рекомендаций.

## Задачи исследования

- Проверить качество данных, обработать пропуски, дубликаты и некорректные типы.
- Разделить компании по длительности финансирования и сегментам рынка.
- Выявить аномально большие объёмы финансирования и учесть их при анализе.
- Сравнить типы финансирования по распространённости и объёму инвестиций.
- Изучить изменение числа раундов и размеров инвестиций по годам.
- Оценить динамику финансирования по массовым сегментам рынка и долю возвращённых средств по типам финансирования.

**Среда:** Jupyter Notebook.

# Анализ рынка стартапов и венчурных инвестиций

## О проекте

Исследование исторических данных о стартапах и их финансировании по 2014 год включительно. Цель — оценить состояние венчурного рынка и определить перспективные направления инвестирования **с позиции начала 2015 года**.

Проект выполнен в формате аналитического кейса: от подготовки данных до анализа структуры рынка, динамики инвестиций и формирования рекомендаций.

## Задачи исследования

- Проверить качество данных, обработать пропуски, дубликаты и некорректные типы.
- Разделить компании по длительности финансирования и сегментам рынка.
- Выявить аномально большие объёмы финансирования и учесть их при анализе.
- Сравнить типы финансирования по распространённости и объёму инвестиций.
- Изучить изменение числа раундов и размеров инвестиций по годам.
- Оценить динамику финансирования по массовым сегментам рынка и долю возвращённых средств по типам финансирования.

## Инструменты

**Python:** pandas, Matplotlib, seaborn.  
**Среда:** Jupyter Notebook.

## Основные результаты
- 58,94% компаний имели единственный раунд финансирования. При этом на компании с периодом финансирования более года приходилось 61,9% общего объёма инвестиций.
- Наиболее распространённый тип финансирования в исследуемых данных — венчурные инвестиции; они также лидировали по суммарному объёму привлечённых средств.
- К 2014 году наблюдалось снижение числа раундов финансирования, начавшееся в 2013 году.
- Среди направлений с заметным ростом объёмов финансирования к 2014 году выделены медицина, приложения, недвижимость, SaaS и интернет.
- В динамике доли возврата средств венчурные инвестиции продемонстрировали наиболее стабильный рост начиная с 2009 года, согласно результатам исследования.
Итоговая рекомендация в рамках исторического кейса: обратить внимание на компании с длительным периодом финансирования, венчурный формат вложений и растущие сегменты рынка, перечисленные выше.
